# Supported modes and remaining limits

Supported: English plain-text employment-resume content, one supplied fixed template, explicit original-material/JD input, model-assisted first draft and source-linked edits, deterministic structure, local LibreOffice rendering, mechanical measurements, manual source/image/writing review and immutable delivery.

Unsupported: Chinese or bilingual output, arbitrary user-template interchange, photo insertion/editing, automatic clickable hyperlinks or link-target validation, academic CVs, employer-specific application forms, automatic prose truth/quality grading, a bundled local model, provider API integration, credentials/accounts, publishing and application submission. Plain contact or URL text can appear as supplied text; that does not create or verify a clickable link. Do not present an unsupported feature as completed merely because source instructions once described it. Choose another authorized workflow for those modes.

Observed testing uses a WSL2/Linux environment with pre-existing dependencies and exact licensed fonts. Native Windows/macOS, native Microsoft Word, other renderer/font versions, real ATS ingestion, broad overflow recovery and OS-wide filesystem/network/credential isolation remain unverified. See INSTALLATION-VALIDATION.md for historical measured scope and the current RC4 validation boundary and VERSION-DELTA.md for the RC1 → RC2 → RC3 → RC4 delta chain.
