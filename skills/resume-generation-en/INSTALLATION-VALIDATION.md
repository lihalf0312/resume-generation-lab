# RC4 validation scope

RC4 preserves the seventeen original invariants and adds generic accepted-render/workdir boundary regressions in tests/test_render_acceptance.py. The latter use explicit deterministic test doubles for unit coverage; they do not claim actual renderer behavior. Separate private integration runs exercise real local LibreOffice conversion, measured DOCX/PDF token matching and embedded-font inspection, with a clearly labelled injected post-measurement font-validation failure, correction and bounded retry. Any naturally observed renderer failure retains its actual returncode and diagnostics and consumes an attempt.

Final release freeze and independent A/B results belong to a separate accompanying acceptance report after the implementation is fixed for inspection. No A/B outcome or model-quality conclusion is claimed here. The original RC3 installation account below is historical evidence only, not an RC4 clean-install result. Runtime setup still requires operator-supplied fonts, dependencies and renderer; native Word/other OS/ATS/semantic truth remain unverified.
