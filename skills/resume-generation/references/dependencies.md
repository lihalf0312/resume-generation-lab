# Dependency inventory

## Included
- Public skill instructions, agent display metadata, formatting rules and machine-readable contract.
- Private-data boundaries and a template-independent project interface.

## Not included in the uploaded skill or public edition
- Actual Chinese/English DOCX templates, approved historical document baselines and original package members.
- Exact font families/sizes, numerical margins, tab-stop values, photograph sizing/position, body-area bounds and quantitative bottom-whitespace tolerance.
- Applicant evidence, experience/correction/retirement databases, course inventory, photos, contacts, private feedback, project status, generated prior resumes and the separate personal migration archive referenced in the export note.
- Runtime dependencies: Word or equivalent DOCX export engine, PDF rendering/extraction tools, needed fonts, document/PDF skill packages, skill-validator implementation.
- An executable generation/rendering pipeline. The uploaded archive contained only Markdown/YAML/text, no runnable generator.

Before claiming template fidelity, obtain the actual authorized templates and establish their measured layout. A synthetic test may use an independently declared provisional template, but must not claim it reproduces the absent original. Before claiming successful rendering, inspect the actual runtime and outputs. This inventory describes attachment completeness, not which software a particular environment currently has installed.
