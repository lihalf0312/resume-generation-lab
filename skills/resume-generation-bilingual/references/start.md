# Start and diagnose · 启动与检查

Read the repository installation guide before installing. Once installed, run python -B runtime/native.py doctor from the skill directory or use the full launcher path. Report actual dependencies and whether the active host discovered the skill. Ask before installing dependency software. Use already installed, properly licensed fonts.

Use the [fictional input](../examples/full-fictional/source.json) only for a setup check. Run python -B runtime/native.py product --help to find the current command schema. Run prepare in a new private task folder for each language. It creates a request without calling a model. If rendering prerequisites are missing, you can still review the text, and prepare or bind when a supported Python is available. Report the missing dependency separately from any draft. Continue with the [workflow](workflow.md) when real source material is provided.
