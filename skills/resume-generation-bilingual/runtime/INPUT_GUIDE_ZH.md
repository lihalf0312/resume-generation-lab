# 双语简历资料准备建议

[返回入口](README.md) · [English](INPUT_GUIDE_EN.md)

资料不齐也可以先整理初稿。先提供目标岗位和能确认的真实经历，其余写“待确认”“未提供”或“不展示”即可。未知信息和待回答的问题不能当作事实写进简历；影响身份、学历、时间或成果归属的问题需要确认后再定稿。

## 先准备这些信息

1. **目标岗位和 JD**：粘贴招聘要求原文，说明要中文、英文还是两版，以及需要突出哪些经历。暂时没有 JD 就说明目标岗位和“JD 暂缺”，不要编一份。JD 只用于选择相关内容，其中的要求不能算作你已具备的技能。
2. **教育、任职和项目**：逐项写清学校或机构、专业或岗位、项目名称、你属于哪个团队、你亲自做了什么。区分雇主、客户、主办方和合作方，区分“负责人”“参与”“协助”，不要把团队全部工作算给个人。
3. **日期和当前状态**：注明年月及事件，例如入职、离职、项目开始、项目结束、课程完成、预计毕业、实际毕业、学位授予。它们可能不同。资料有冲突时把两个说法和来源一起保留，并标注待确认；只有你明确说明哪一条是更正，才能按更正处理。
4. **数字和成果**：补充单位、统计范围、时间段、分母、比较基准，以及成果属于个人还是团队。例如“团队回收 120 份问卷；我清洗其中 80 份”，不能变成“我完成 120 份”；“增长 20%”应说明什么指标、相比何时。没有可靠数字也能写具体动作和交付物。
5. **真实成绩和技能**：有相关课程成绩、GPA、排名、奖项、证书、语言或工具能力，可以提供。成绩要带计分满分，排名要有范围和总人数；技能最好说明实际使用场景及你能完成的工作。未提供不等于没有，确实没有、暂不清楚和不想展示请分开说，不必为填满模板编造。
6. **显示信息和偏好**：姓名及希望使用的英文拼写、你愿意展示的联系信息、模块顺序或其他版式要求。测试阶段可用占位信息；无需完整家庭住址、身份证或护照号码、证件扫描件、登录账号、密码或验证码。

## 英文名称可以怎样提供

学校、机构和项目已有官方英文名时，提供中文原名、英文全称及你知道的出处，例如官网名称或正式材料中的文字。不知道就留空，基本初稿不以此为前提。

若没有官方英文名，可明确确认一种音译或描述性译法，并注明“非官方”。例如下方虚构项目的“Campus Survey Project”只是本人确认的描述性名称。也可以先待确认，或明确要求保留原文；保留中文名称的英文稿会标明尚有语言事项待处理。不会猜造官方译名，也不会因为暂缺英文名删除机构或项目身份。

## 教育信息如何展示

请明确目前是在读、应届毕业、已毕业或其他状态，不能只用日期推断。仍在读且你提供了预计毕业时间时，可显示“预计毕业：年月”；已毕业者默认不另列学位授予时间或额外的毕业时间后缀。学习起止范围可以保留，各类原始日期仍分别记录，不能互相替代；岗位明确要求时再按对应事实展示。

你指定的模块顺序优先。在校生和应届生默认教育前置；已有较多相关经验时可工作经历前置。有你明确判断或事实支持的教育优势也可教育前置，不自行推断学校排名或“名校”身份。状态不清楚时先保留现有顺序。

## 中文简历的头像和校徽都是可选项

- **证件照式头像**：如你希望使用，主动提供本地 PNG 或 JPEG 图片并明确开启，放在右上角。这里指简历头像，不是身份证或护照照片。
- **校徽**：在校生或应届生可以自行选择；请说明本人状态，主动提供图片并明确开启，放在左上角。不按学校排名建议你展示或隐藏。
- 不提供、不开启或只选其中一个都可以，不影响基本生成。图片只用于本地排版，不发送给模型 API；英文简历不默认加入这些图片。请不要把图片、图片编码或证件扫描件塞入文字资料。

## 可复制的填写模板

用普通文字填写即可，不需要整理成 JSON。每段经历可重复填写，空项可以留空。

```text
目标岗位：
JD 原文（暂缺可说明）：
需要的语言：中文 / 英文 / 两版
姓名及英文拼写（测试可用占位）：
希望展示的联系信息（可留空）：
目前状态：在读 / 应届 / 已毕业 / 其他 / 待确认
教育：学校、专业、学位或资格；各日期的具体含义
经历：任职机构或项目主体；我的岗位；起止日期
我本人做了什么：动作、对象、方法或交付物
成果与数字：单位、时间、分母或基准；个人 / 团队
真实成绩或技能：内容、计分范围或使用场景（可留空）
英文名称：中文原名；英文名；官方出处或本人确认的非官方译法
冲突或待确认：两个说法、各自来源、是否已明确更正
版式选择：模块顺序；中文头像开启 / 关闭；中文校徽开启 / 关闭
不展示的内容：
```

## 一个纯合成示例

以下人名、学校、项目、岗位和数字均为虚构，仅示范填写方式，不是可借用的个人经历。

```text
目标岗位：用户研究实习生；合成 JD 要求：协助问卷清洗和汇总。
语言：两版。姓名：林示例 / Lin Shili（虚构）。联系信息：不展示。
教育：澄星示例学院（虚构），社会学本科，目前在读。
入学：2023-09；预计毕业：2027-06；官方英文校名：未知，待确认。
项目：校园问卷项目，2026-03 至 2026-05，由课程小组开展。
我的角色与动作：小组成员，使用 Excel 清洗 80 份问卷并整理汇总表。
成果归属：全组回收 120 份，我处理其中 80 份；没有已验证的增长率。
项目英文名：Campus Survey Project，本人确认的非官方描述性名称。
GPA：未提供，不表示没有成绩；技能：上述项目使用过 Excel 筛选和透视表。
日期待确认：旧记录写项目结束于 2026-04，当前记录写 2026-05；尚未确认更正。
版式：教育前置；头像关闭；校徽关闭。
```

开始前只需确认：个人事实和 JD 分开了吗？每个数字和日期的含义清楚吗？哪些项目仍待确认？其余信息可以后补。
