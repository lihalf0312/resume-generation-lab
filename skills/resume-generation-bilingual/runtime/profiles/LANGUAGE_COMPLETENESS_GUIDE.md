# 英文语言完整性与可选输入

英文中出现原始中文机构名不等于虚构事实，但不能在未说明的情况下当成完整英文成品。预览始终保留；语言待确认与基本生成失败必须分开。

入口 audit_language(doc_or_deliverable, source, language, bindings=None) 检查可见内容中的汉字，给出稳定unit/span ID、按人名/学校/机构/项目/术语/正文的结构分类提示、原始源位置和待选择事项。不会把所有非ASCII字符拦掉；中文可保留Latin技术词、人名，英文的变音字母和数学符号也不被当中文。没有汉字只说明此机械预检未命中，绝不证明整篇确为英文或翻译准确。说明和澄清问题不属于简历可见正文，不受同一语言限制。

优先使用材料明确给出的英文名。有官方名称可提供，但不是必填信息。没有时，可以保留源身份的草稿，请用户选择已知英文名、允许音译/非官方描述性译法，或明确保留原字样。不得悄悄删除机构，也不得把“要英文”当作允许编造官方命名。

bindings采用language-name-bindings-v1，其entries逐项含binding_id、source_text、output_text、category、authority、authority_reference、source_refs和unit_ids。authority区分源提供英文、源声称官方、用户确认官方、已核验官方、用户批准音译/描述性译法、用户要求原文和源审通过的技术字面量。源引用必须为M材料，不以JD证明个人身份。用户/核验权限由调用方从可信历史取得，不能把模型输出的“已批准”当授权。引用出现或authority字段存在都不自动证明官方身份或翻译对应关系。

build_language_patch(raw_document, source, bindings)只对非空unit_ids明确列出的节点做最长原字串匹配，返回标准受控PATCH或None。学校名与资料室名重叠时，最长匹配优先。角色、日期及其他字符不改；不调用词典、API或模型，不创造译名。空unit_ids只供生成上下文，不许可自动批量替换。新稿必须完整源审与重新渲染。

## 给使用者的建议（非必填）
- 如果知道学校、机构、项目的官方英文名，提供后可提高英文准确性。
- 提供本人希望使用的英文姓名拼写，减少姓名对应不确定性。
- 不知道官方英文名也能先生成草稿，之后再选择允许的音译、非官方描述性译法或保留原名。
- 中文简历的校徽和证件照是可选项，只在用户主动提供并开启时使用；不据此评价学校，缺失不阻止基本生成。

没有新API实测；测试验证脚本、绑定及替换约束，不证明模型已改善翻译质量。
