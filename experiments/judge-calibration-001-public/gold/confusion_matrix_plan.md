# Predeclared diagnostic plan
This is an independent synthetic evaluator-calibration dataset, not development completion or model-weight training. All 12 profiles, employers, institutions, and JDs are fictional and newly authored. There are 3 truthful controls and 9 intentionally defective cases. No reviewer was contacted in creation.

Send only the individual JSON files in blind_inputs/ to the judge with its existing evaluation instruction/rubric. Do not send this directory, gold files, authoring materials, counts, defect categories, or the manifest to the judge. File IDs and ordering do not encode a label. Freeze and verify SHA-256 before submission; record judge version/prompt and raw outputs separately. Never revise cases or labels after seeing responses.

Primary binary target: factual issue requiring correction or verification (positive). For each response, code predicted positive only if it identifies a specific unsupported, conflicting, or inaccurate resume claim from these sources; unrelated style suggestions or merely a below-perfect overall score are not detection. Gold-positive cases are true positives only if the expected injected issue is identified; unrelated alleged defects do not rescue a missed injection. A gold-negative control with an alleged factual issue is a false positive. Negative gold-positive cases are false negatives. Gold-negative cases without alleged factual issues are true negatives. Record any unrelated alleged issue separately so specificity is not hidden.

Expected perfect diagnostic matrix (not an observed result): TP=9, FN=0, FP=0, TN=3. Report observed raw counts, sensitivity=TP/9, specificity=TN/3, and exact issue-detection count per category. All nine categories have only one case, so do not infer robust category accuracy or population performance. For the contradiction case, flagging unresolved evidence and requiring review counts as detection; choosing a definite correct end date without justification does not. For the bilingual mismatch case record whether each of the two injected spans was detected, alongside case-level any-detection. Show controls individually and distinguish scores from factual detection. A ceiling on truthful candidates alone is not evidence of judge reliability.

Keep gold isolated from judge context. This corpus is evaluator diagnostic only, not counted toward the requested 30 generated development pairs. No scoring rubric was applied by the corpus author; gold contains only known factual expectations.
