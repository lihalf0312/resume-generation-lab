# General evaluation specification

`rubric.json` describes a provisional factual-fidelity gate and presentation dimensions. `sources.json` contains the historical primary-source references used to inform the general specification. The weights and criteria are not empirically calibrated hiring rules.

No case-specific design corpus, preset answers, seeded gold labels or detailed review bases are distributed here. Development examples publish only original dimension ratings and short comments under `data/development-140/`.

Faithfulness to fictional supplied facts is not real-world truth verification. Native labels and ratings are not HR ground truth or demonstrated model quality. Actual artifact readability requires separate rendered-document checks, which this content-only dataset does not provide.
